АВАРИЯ В ХИМИЧЕСКОЙ ЛАБОРАТОРИИ · Оптимизированная версия для GitHub Pages

УСТРОЙСТВО
index.html — единственная страница запуска.
levels/ — двенадцать отсеков (отдельные небольшие HTML).
assets/media/ — картинки WebP и PNG вместо встроенных Base64.
assets/css/ — стили отдельно от HTML.
assets/js/ — игровая логика и система результатов.
results.html — итоговый журнал и рефлексия.

ПУБЛИКАЦИЯ НА GITHUB
1. Откройте репозиторий GitHub, в котором публикуете игру.
2. Загрузите ВСЕ содержимое распакованного архива, сохраняя относительные пути
   index.html, results.html, папки levels и assets.
3. Не загружайте только один index.html без папок. Папки браузер использует сам.
4. Откройте GitHub Pages по адресу вашей публикации с /index.html в конце,
   или по ссылке на корневую страницу публикации.
5. На образовательном сайте замените ссылку на старую игру адресом нового index.html.
6. Если сайт встраивает через iframe, размер iframe задаётся В РЕДАКТОРЕ САЙТА.
   Задайте ширину 100%, высоту около 95vh и не фиксируйте маленькую высоту 250–400px.
   Для телефонов лучше открывать игру отдельной вкладкой/кнопкой: у детей будут
   нормальная высота и крупные элементы управления.

МОБИЛЬНЫЙ ЭКРАН
Отсеки 2–10: панель с крупными вопросами и ответами ПОД сценой.
Отсеки 1,11,12: расширенный вертикальный режим, логика оригинала сохранена.
На смартфоне прокрутка одной страницы по вертикали допустима для чтения;
горизонтальной прокрутки быть не должно. На компьютере игровая сцена масштабируется
по высоте окна. Если сайт зажал внешний iframe, внутренний HTML расширить его не может.

ПРОВЕРКА
Случайные ошибки не были заменены заранее заданными результатами.
Журнал остаётся в localStorage данного браузера и используется в results.html.
Для достоверной статистики открывайте игру только через index.html.

ЭКОНОМИЯ ДАННЫХ
Браузер скачивает отдельный отсек только при его открытии и сохраняет медиа в кеше.
Это уменьшает первоначальную загрузку. Поведение доступа без VPN зависит от
GitHub Pages и сетевых настроек и одной этой оптимизацией не гарантируется.

ВАЖНО
В папке файловой системы Chrome может ограничивать взаимодействие с вложенными
HTML из соображений безопасности. Финальное целевое окружение — GitHub Pages (HTTPS).
