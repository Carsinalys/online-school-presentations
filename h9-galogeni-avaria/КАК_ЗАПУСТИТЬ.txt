АВАРИЯ В ХИМИЧЕСКОЙ ЛАБОРАТОРИИ — 12 ОТСЕКОВ + ИТОГОВЫЙ ОТЧЁТ

1. Распакуйте архив целиком. Не извлекайте один файл index.html отдельно.
2. Откройте FINAL_LAB_GAME/index.html. Если браузер блокирует сохранение
   результатов при запуске с диска, разместите всю папку на GitHub Pages.
3. Начинайте игру с первого отсека. В главном меню можно открыть любой отсек.
4. После шестого задания 12-го отсека автоматически откроется итоговый отчёт.
   Его также можно открыть кнопкой «Мои результаты» или через меню.
5. В отчёте будут РЕАЛЬНО ЗАПИСАННЫЕ ошибки, правильные ответы с первой попытки,
   подсказки, список трудных тем, тренировка и личная рефлексия.
6. Ученику можно нажать «Скачать индивидуальный отчёт (HTML)» или «Распечатать».
7. Все записи хранятся ЛОКАЛЬНО в браузере. Если очистить данные браузера или
   открыть игру на другом устройстве, прежний журнал не появится автоматически.
8. Статистика недоступна за попытки, совершённые в старых версиях игры до
   подключения журнала. Эти результаты НЕ ПОДМЕНЯЮТСЯ вымышленными баллами.

СТРУКТУРА:
  index.html          — главное меню и навигация по 12 отсекам
  levels/01.html ... levels/12.html — интерактивные игры
  results.html        — спасённая лаборатория, результаты, рефлексия, повторение
  assets/             — фоновое изображение спасённой лаборатории
  training_core.js    — локальное сохранение результатов
  results_logic.js    — анализ ответов, рекомендации и экспорт отчёта

ДЛЯ GITHUB PAGES:
  Загрузите содержимое папки FINAL_LAB_GAME в корень репозитория,
  затем включите Pages с публикацией из основной ветки / (root).
  Для запуска используйте адрес опубликованного index.html.

ПРИМЕЧАНИЕ ОБ ИГРОВОЙ МЕХАНИКЕ:
  Индикаторы опасности и восстановления отражают сюжетный прогресс.
  Это не школьная отметка и не процент правильных ответов с первой попытки.
  Подробная учебная оценка находится в results.html.
